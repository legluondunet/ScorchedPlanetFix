# Dither state isolation probe v5

Retains v4's two lighting BMPs and flushed PROBE.LOG. Adds DITHER.BIN: four fresh frames at identical geometry and coordinates using msiSetParameters requests 0,1,1,0; when msiSetDitherEnable is exported, four more fresh frames with (request,override) = (0,0),(0,1),(1,0),(1,1). Each frame is cleared, renders identical synthetic rectangles, samples 2048 interior RGB565 pixels in direct framebuffer mode, then ends before the next frame. No explicit blend override in this matrix. One short binary report (16408 or 32808 bytes) plus PROBE.LOG is sufficient. New test is intended to distinguish order dependence, request polarity and explicit setter behavior within this driver/emulator environment; it does not establish physical hardware behavior. Existing renderer is unchanged. Run from a new writable folder next to the original MSI95.DLL; BMP and DITHER.BIN files are CREATE_NEW.
