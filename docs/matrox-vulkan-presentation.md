# Native Vulkan presentation proof (issue #73)

Standalone synthetic test only, not installed or bundled in ScorchedPlanetFix. Uses the Windows x86 Vulkan loader from system32 (Wine's vulkan-1.dll under Wine), core Vulkan 1.0 and Win32 surface/swapchain extensions. The build pins Khronos Vulkan-Headers at b379292b2ab6df5771ba9870d53cf8b2c9295daf (v1.3.290); headers only, Apache-2.0. No DXVK, Vulkan SDK runtime, shader compiler or game assets. Converts synthetic RGB565 to RGBA8 on CPU for this first proof; GPU performs linear transfer blit into centered 4:3 viewport. This requires an eligible non-CPU adapter, one graphics/present queue family, optimal-image linear blit source and supported swapchain blit destination and transfer-destination usage. No claim that every Vulkan-capable driver supports this exact path. Native RGB565 upload may be optimized later with capability checks.

Exit 0 = test passed; 77 = runtime/device unavailable (not a GPU pass); 1 = failed test after device selection or CPU self-test. CI verifies x86 compilation and CPU conversion/viewport, and runs presentation when possible. No artifact upload. This is a single-frame proof, not a performance benchmark. The full backend must reuse staging resources and command buffers, handle swapchain recreation and per-image presentation semaphores, avoid per-frame device idle, support nearest/linear and preserve the original HWND/input lifecycle. Device loss/unavailable hardware must fall back to GDI in auto mode. Only expose Renderer=auto|vulkan|software once integrated and validated. Higher-resolution 3D is a separate milestone. No defaults or existing MSI95 code changed.

## Revision 2

180 changing synthetic frames; persistent mapped staging and reusable command buffer/fence, per-swapchain-image presentation semaphores, no per-frame device idle. FIFO timing includes refresh wait and is not directly comparable to game raster/presentation timing. Fixed-size window; resize/device loss recovery remains an integration requirement. Writes VulkanProbe.log and VulkanProbe-error.log. CI #2 compiled x86 and passed CPU self-test, but the runner returned VK_ERROR_INCOMPATIBLE_DRIVER (-9); PowerShell's implicit propagation of exit 77 marked the step failed. Explicitly accept only expected no-runtime cases; other instance creation errors fail. One small short-lived x86 artifact is now necessary for real GPU validation on owner hardware; no full launcher builds or additional artifacts.

## Owner hardware result / reusable presenter

On RADV NAVI23 RX 6600M, Wine x86 v2 reported 180 frames in 1504.47 ms (8.358 ms/frame, FIFO wait included), exit 0; no visual pixel-readback verification. Extract shared presenter with caller-owned HWND, explicit open/present/close lifecycle, fixed 640x400 RGB565 input and pitch, selectable nearest/linear filter, and safe failure return for resize/minimize. Synthetic harness exercises the same code intended for integration. No new downloadable artifact until integration. Native game integration and no-CRT DLL build still pending.

## First MSI95 integration

Experimental default Renderer=software; Renderer=auto or vulkan requests Vulkan and safely falls back to existing GDI if unsupported or presentation fails. For this initial milestone even explicit vulkan uses fallback instead of failing the legacy game's initialization; strict forcing and auto default deferred until game tests. PresentationSmooth=1 selects GPU linear, 0 nearest. Existing software path still uses GDI HALFTONE/legacy respectively, F12 and all native CPU raster behavior unchanged. Vulkan initialization delayed until outer MSI end frame; no additional HWND or Win32 message loop; skip minimized windows, release on WM_DESTROY or MSI cleanup. Size change currently permanently falls back to GDI rather than recreating swapchain. FIFO includes refresh wait; session logs separate Vulkan present time from legacy aggregate gdi_ms (historical name). No CRT or new DLL shipped; Vulkan-Headers pinned, x86 nine-export ABI audit retained. CI exercises auto mode with existing synthetic lighting probe, native color validation and either Vulkan success or GDI fallback. Full launcher CI only on stacked PR, no extra prototype/lighting artifact.
